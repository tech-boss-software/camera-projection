# Geometry system card

- **Method:** deterministic calibrated pinhole projection and convex half-space segment clipping.
- **Inputs:** synthetic 3D vertices, fixed camera intrinsics and yaw/position.
- **Assets:** all scene geometry generated by this repository; no external data or client assets.
- **Validation:** analytic unit tests and reproducible visibility accounting, with actual output in `examples/`.
- **Intended use:** educational reference and testable geometry baseline.
- **Limitations:** no learned weights, depth estimation, pose estimation, physical calibration, occlusion reasoning or lens model. A visually plausible render is not proof of real-camera accuracy.
- **Next validation:** compare projections against a trusted calibrated-image dataset and add full rotation matrices, distortion and raster-depth tests before deployment.
